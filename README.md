#  Random Task Generator

Приложение для генерации случайных задач с графическим интерфейсом на Python.  
Помогает разнообразить день и внести элемент случайности в выполнение задач.

**Александра Сивкова**  
Апрель 2026

## Описание

Random Task Generator - это приложение, которое:
- 🎲 Генерирует случайные задачи из вашего списка
- 📝 Позволяет добавлять собственные задачи
- 🏷️ Поддерживает категоризацию задач (учёба, спорт, работа)
- 📜 Сохраняет историю сгенерированных задач
- 🔍 Фильтрует историю по типу задач
- 💾 Автоматически сохраняет данные в JSON

##  Возможности

- ✅ Генерация случайной задачи при нажатии кнопки
- ✅ Добавление новых задач с выбором типа
- ✅ Удаление существующих задач
- ✅ Отображение последней сгенерированной задачи
- ✅ История всех сгенерированных задач с временными метками
- ✅ Фильтрация истории по типу задачи
- ✅ Очистка истории
- ✅ Сохранение данных в JSON при каждом изменении
- ✅ Загрузка данных при запуске приложения
- ✅ Валидация ввода (проверка на пустые строки)
- ✅ Анимация при генерации задачи

##  Требования

- **Python 3.8+** - язык программирования
- **Tkinter** - библиотека для GUI
- **Random** - генерация случайных задач
- **JSON** - хранение данных
- **Unittest** - тестирование
